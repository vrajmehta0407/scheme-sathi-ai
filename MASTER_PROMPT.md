# Scheme Sathi AI: Master Prompt for Antigravity

Paste everything below the line into Antigravity as the first prompt. Attach `PRD.md`, `design.md`, `architecture.md` and `agents.md` so the agent can read them.

---

Before writing any code, read the four attached docs completely, in this order: PRD.md, architecture.md, agents.md, design.md. Treat them as the single source of truth. Priority if they conflict: PRD, then architecture, then agents, then design.

You are a senior full-stack engineer, data analyst and award-winning product designer. Build **Scheme Sathi AI**: a web app that helps Indian citizens discover government welfare schemes they qualify for, with a rules-based eligibility engine, document checklists, application tracking, a benefit calculator, a citizen dashboard and a full analytics workbench over a synthetic population dataset. Work autonomously in stages, and verify each stage in the browser before moving on.

## HARD CONSTRAINT: NO API KEYS
Do not use any API key, paid service, cloud database, LLM API, CDN script, Google Fonts, map tiles or analytics. Everything must run locally with one command and work offline after first load. Plain-language text comes from templates over computed facts, not from an AI service. If you are tempted to add an external service, use a local alternative instead.

## Stack
Next.js 15 (App Router) + TypeScript + Tailwind CSS + Framer Motion + GSAP ScrollTrigger + Lenis; Zustand, TanStack Query, TanStack Table + Virtual; Recharts + visx; d3-geo with a bundled India TopoJSON for the map; Fuse.js for search; next-intl for English/Hindi/Gujarati; SQLite (better-sqlite3 + Drizzle ORM) as a local file; Auth.js credentials (optional local accounts, `AUTH_SECRET` auto-generated by the setup script); pdf-lib for PDF export; Serwist/next-pwa for offline; Vitest + Playwright. Fonts self-hosted via `next/font`.

## Design Requirements (critical)
- **Light theme only, no dark mode.** Colourful, glassmorphic, Pinterest-style masonry, animated jaali (lattice) background. It must NOT look like a generic AI template.
- **Exactly three colours:** two main colours, Civic Blue `#1479FF` and Sunbeam Yellow `#FFC20E`, plus one different accent, Parrot Green `#12B76A` (used for Eligible / success, about 5-10% of a screen). Neutrals: Midnight Navy `#0A1A3C`, White, Sky Mist `#F0F6FF`.
- **Do NOT use any of these colours, which belong to other projects:** violet, lime, tangerine/orange, teal, pink/berry. No cream, no beige, no red alarm styling.
- Yellow is never used for text; use navy text on yellow.
- Fonts: Sora or Outfit (display), Manrope (body), IBM Plex Mono (numbers), Noto Sans Devanagari and Gujarati for Indic text.
- Animations: staggered reveals, Framer layout animations when filters change, count-ups, chart draw-ons, tilt-on-hover pins, scroll-pinned landing story, marquee of scheme names in three languages, blob cursor follower, confetti in brand colours, slowly rotating rangoli pattern. Honour `prefers-reduced-motion` and WCAG AA.

## Build Order
1. **Scaffold:** monorepo-style structure from architecture.md, Tailwind tokens, jaali background, glass utilities, fonts, i18n skeleton, `npm run setup` script (installs, creates DB, generates AUTH_SECRET, seeds data).
2. **Data:** write `data/schemes.sample.json` with about 40 schemes (central plus a few Gujarat ones across farmers, students, women, seniors, workers, health, housing, entrepreneurs) with English/Hindi/Gujarati names and summaries, rules, documents, steps, official links, `last_verified`. **Mark all of it as SAMPLE data to verify on official portals.** Write the seeded synthetic population generator (about 20,000 households, flagged synthetic).
3. **Rules Engine:** JSON-DSL evaluator with all/any/none, near-miss distances, Eligible/Likely/Not eligible, plus 150+ Vitest golden cases and a property test.
4. **Landing page:** hero, marquee, pinned 3-step story, interactive income-slider demo, category masonry, dashboard preview, privacy promise, CTA.
5. **Sathi Wizard:** one question per card, live "schemes found" counter, information-gain next-question logic, multiple saved profiles, language switcher.
6. **Scheme Board:** masonry pins, Fuse.js search, filters, bookmarks, compare (up to 3), Framer layout animations.
7. **Scheme Detail:** eligibility meter, "Why?" criteria list via template explainer, near-miss ribbon, documents, steps, benefit estimate, official link.
8. **What-if Simulator:** sliders for income, age, land, occupation; pins animate in and out; show gained/lost schemes.
9. **Documents + Tracker:** merged checklist wallet, readiness percent, PDF export, application state machine with in-app reminders.
10. **Citizen Dashboard:** KPIs, estimated annual benefit hero counter, category donut, deadlines, document readiness, application funnel, missed-benefits list.
11. **Analytics Workbench:** Overview, India coverage map, Funnel, Blockers, Cohort comparison, Overlap matrix; filters, drill-down, virtualised data table, CSV and PNG export, saved views, template-written insight pins, "Synthetic data" badge, minimum cell size 30.
12. **Admin Console:** scheme CRUD, visual rule builder, CSV/JSON import, validation report (Admin Quality checks), version history, audit log.
13. **Privacy + Polish:** export and delete data, clear-all button, PWA offline, skeletons, empty and error states, strict CSP (`default-src 'self'`), Lighthouse above 90, responsive 4/2/1 masonry.

## Rules
- Unknown is never "yes": missing profile fields produce "Likely".
- Never claim guaranteed eligibility; every result shows "Verify on the official portal".
- Every sentence shown to users must be traceable to a rule result, calculator output or catalogue field.
- Stats must reconcile (state totals equal national total); always show sample sizes.
- Write tests for the rules engine, benefit calculator, analytics reconciliation and a Playwright flow (wizard, board, what-if, checklist, dashboard filter, language switch).
- Produce a README with setup (`npm run setup`, `npm run dev`), data notes and how to add a scheme. No API-key section is needed because none exist.

## Definition of Done
A citizen can open the app with no login, answer a short wizard in English, Hindi or Gujarati, instantly see ranked schemes with plain-language reasons, near-miss hints and what-if sliders, get a document checklist and track applications, view a personal dashboard, and an analyst can explore the analytics workbench with map, funnel, blockers, cohorts and exports, all inside the blue-and-yellow-with-green-accent glassy masonry UI, running locally with one command and no API keys.
